# Flourtrack - Sistem Inventory Rumah Produksi Kue dan Oleh-Oleh

Sistem Inventory berbasis Laravel untuk pengelolaan rumah produksi kue dan oleh-oleh.

## Detail Infrastructure & Hosting
- **Domain**: [http://flourtrack.sucicookies.my.id](http://flourtrack.sucicookies.my.id)
- **Database**: MySQL (`sql_flourtrack`)
- **Framework**: Laravel 12 / PHP 8.3
